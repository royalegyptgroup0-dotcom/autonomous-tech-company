### المراجعة الفنية

تمت مراجعة تنفيذ التنقل للتحقق من النقاط التالية:

- توحيد إدارة حالة القائمة من خلال `setMenuState()`.
- مزامنة فئة CSS `open` مع `aria-expanded` و`aria-label`.
- إغلاق القائمة عند الضغط على رابط تنقل.
- إغلاق القائمة عند الضغط على `Escape` مع إعادة التركيز إلى زر القائمة.
- إغلاق القائمة عند النقر خارج زر القائمة ومنطقة التنقل.
- إعادة ضبط الحالة عند الانتقال إلى عرض سطح المكتب باستخدام `matchMedia('(min-width: 721px)')`.
- عدم استخدام مصيدة تركيز (focus trap) لقائمة تنقل عادية.
- إضافة اختبارات انحدار آلية دون إضافة مكتبات خارجية أو تكلفة تشغيلية.
